# 마포한끼

상인 팀의 밀키트 원안을 우리 집 재료·예산·조리 여건에 맞춰 바꾸는 전통시장 모바일 웹 시제품입니다.

## 공개 체험

[마포한끼 체험판](https://lkjh098-cell.github.io/traditional-market-ai-contest/)

공개 체험판은 규칙 기반 시연입니다. 실제 AI 호출·결제·배송은 발생하지 않습니다. 모든 점포·가격·재고·레시피는 가상 데이터이며 시장 공식 서비스가 아닙니다.

## 전체 개발 소스

[mapo-hankki-source.zip](./mapo-hankki-source.zip)에 실제 AI 서버·D1 데이터 구조·고객 화면·테스트·개발 README를 포함했습니다. 압축을 풀고 README.md의 실행 안내를 확인하세요. 저장소 루트 파일은 GitHub Pages용이며 실제 AI 서버는 별도 배포가 필요합니다. API 키·비밀 환경파일은 포함하지 않았습니다.

## 2026-10-05 수정

- LLM 의도 해석 → 서버 가격·재고·허용 여부 계산 구조 유지.
- 요청 시점 catalog로 원안·재료·대체 규칙 ID enum 생성.
- 항목별 입력 원문 evidence·해석 이유 reason과 서버 인용 대조.
- 입력에 없는 근거·중복 변경은 제외하고 주문 차단.
- 미해결 요청을 not_registered / no_rule / health_claim / ambiguous로 분류.
- AI 거절·응답 중단·잔액 부족·요청 제한·연결 실패·잘못된 응답 구분.
- 실패 시 원안은 사용자가 직접 선택하고 변경 조건 미적용을 확인. 안전 요청은 우회 차단.
- 근거 대조 화면과 22개 오프라인 회귀 테스트 추가. `npm run test:intent`로 실행.

인용이 실제 입력에 있는지 확인해도 의미 해석의 정확성을 완전히 보증하지 않습니다. 실제 모델 생성 성공은 API 크레딧 부족으로 아직 검증하지 못했습니다. 이번 테스트는 모의 응답을 사용해 실제 API 비용이 발생하지 않았습니다.
