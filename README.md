# 마포한끼

상인 팀의 밀키트 원안을 우리 집 재료·예산·조리 여건에 맞춰 바꾸는 전통시장 모바일 웹 시제품입니다.

## 공개 체험

https://lkjh098-cell.github.io/traditional-market-ai-contest/

별도 설치 없이 모바일·PC에서 메뉴 구성, 원안 비교, 참여 점포, 추가 상품, 장바구니와 모의 픽업 예약을 체험합니다.

공개 체험판은 브라우저에서 작동하는 규칙 기반 시연입니다. 실제 AI API 호출이나 결제·배송은 발생하지 않습니다. 점포·가격·재고·레시피는 가상 데이터이며 마포농수산물시장의 공식 서비스가 아닙니다.

## 전체 개발 소스

[mapo-hankki-source.zip](./mapo-hankki-source.zip)에 React/Vinext 웹앱, 실제 AI 서버 연동 코드, D1 데이터 구조, 시연 테스트와 개발 설명서를 포함했습니다. 압축을 풀어 README.md를 확인하세요. 비밀 환경파일과 API 키는 포함하지 않았습니다.

이 저장소의 루트 파일은 GitHub Pages용 공개 체험판입니다. 서버 기능은 별도 배포가 필요합니다.
